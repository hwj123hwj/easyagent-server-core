# 验收与开源边界

状态：计划，不代表已运行测试。版本交付条件见 [RFC](RFC-001-SERVER-RUNTIME.md)。

## 核心合同验证

| 领域 | 必须通过的验证 |
| --- | --- |
| 助手与模式 | 两个 Definition 使用独立工具与会话；Chat/Agent 切换不增加能力；请求不能覆盖模型 endpoint、系统提示或工具定义 |
| 授权 | 无认证拒绝；跨 tenant/账户/助手/资源拒绝；授权适配器缺失时生产启动拒绝；权限撤销在执行、恢复、结果和长订阅中生效 |
| 工具 | 未注册名称拒绝；严格 schema 和业务范围校验；只读适配器输出脱敏；403/404/超时/格式错误分别报告 |
| 预算 | 轮数、工具次数、并发、字节、时间、token/重试限制有效；重复查询停止；用户/模型不能扩大预算 |
| 流式协议 | 任意 UTF-8/网络分片解析；断流不能生成成功；临时文本与最终结果区分；seq 恢复、快照重置和代次切换不混入旧文本 |
| 会话 | 仅提交完整公开轮；活跃轮并发控制；恢复期间的权限变化不带入旧证据；到期数据不出现在列表/上下文 |
| 任务接收 | 相同幂等键返回同一 Run；不同载荷冲突；outbox 与 Run 同事务；取消不通过重连隐式重建 |
| 多 worker | 两 worker 并发领取、崩溃、租约失效、旧 worker 迟到提交、Redis 唤醒丢失或重复，状态一致且陈旧提交拒绝 |
| 接管 | 已完成步骤复用；不确定请求保留预算；Definition 不兼容时中断；取消 Run 不自动恢复 |
| 证据 | 模型编造证据 ID 被拒绝；陈旧快照显式标注；未接入来源不能当作正常；诊断完成不宣称修复 |
| 嵌入边界 | 核心无命令或生产管理工具；宿主只注入必要查询接口，实际后端拒绝越权；明确同进程封装不是 OS 沙箱 |

核心测试用 scripted provider 与 spy ToolExecutor，验证实际请求/状态而非只检查提示词文本。状态和分发用一次性真实 PG/Redis 做 race 与故障恢复；不连接生产、不投递消息、不制造线上失败。

## 虚构公开 demo

两类助手：示例数据分析、示例任务产物排查。四个只读诊断工具使用内存虚构记录，可选择以下案例：

1. 任务尚未到触发时间。
2. 生产任务失败且对应完成标记缺失。
3. 产物存在，但消费者版本不兼容。
4. 对象无读取权限或存储不可达，不能判定为缺失。
5. 完成标记存在，但清单引用的对象缺失。
6. 来源快照过期、运行日志尚未接入。
7. 模型要求执行 shell 或查询其他账户，执行链拒绝。
8. 窗口关闭、刷新、取消或 worker 重启后的任务状态。

所有案例的结果由虚构记录计算，不加入真实域名、人员、运行 ID、账单、日志、存储键、对象正文或生产导出。

## 公共仓库与宿主仓库的划分

| 公开 | 宿主独立维护 |
| --- | --- |
| 通用 model/tool/runner 协议与实现 | 企业统计规则、身份映射、角色名单 |
| 账户/范围授权扩展点与通用协议 | 真实 IAM、内部 URL、组织与权限配置 |
| 通用 PG/Redis 状态适配器 | 业务 SQL、来源表名及生产 schema 迁移 |
| 虚构 demo、协议测试、嵌入及适配示例 | 对象前缀、产物合同、私有日志/API 适配器 |
| 许可证、上游 NOTICE、版本与安全文档 | 凭据、平台导出、线上截图和排查记录 |

设计和实现从通用合同开始，不把私有仓库整体 fork 成公开项目。首次发布前核对所有 tracked 文件、附件和 Git 历史，确认没有将生产信息带入新仓库；秘密扫描是辅助检查，不能替代内容核对。

## 第一个宿主接入的条件

先在隔离环境对接现有身份/权限、只读查询和会话迁移；保持旧接口兼容并可切回。首个宿主采用固定版本源码引入，保留来源/许可清单并适配既有接口；其他宿主可选择普通模块导入。

业务工具和诊断工具必须明确来源证据与未接入状态。企业多 Pod 上线要求 RFC v0.2 的宿主租约、提交与恢复合同通过，并完成真实登录账号下的会话切换、撤权、排查结果和恢复验证。

核心架构不预先覆盖宿主排程、任务意图或源系统；正式发布按宿主既有流程执行。

## 源码嵌入验收

核心清单可在虚构宿主中直接复制、调整 import 并构建；不依赖完整 SDK、私有包、daemon 或新增 RPC 服务。API 与既有 worker 可以编译相同核心并创建各自助手实例；只有 immutable 定义/连接等可共享，不共享可变用户历史。升级来源清单与宿主权限、SSE、会话及多 Pod 回归必须同步核对。
