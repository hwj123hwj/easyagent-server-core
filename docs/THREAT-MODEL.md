# 嵌入式 Agent 的威胁模型

状态：最小核心已有合同测试，真实宿主边界仍需接入验收。修订日期：2026-10-12。当前架构见 [RFC](RFC-001-SERVER-RUNTIME.md)，验证边界见 [验证记录](VALIDATION.md)。

核心源码嵌入宿主应用，限制模型可调用的工具；不要求独立服务，也不提供同进程 OS 沙箱。核心无通用 shell、SSH、kubectl、脚本/生成代码执行、文件编辑、原始 SQL、任意 URL 或动态插件入口。

## 信任与能力边界

受信部分是核心、宿主认证/授权、审批和受审查的工具实现。模型输出、用户问题、历史正文、日志、对象清单与网络响应均不能授予权限。

工具注册元数据来自可信代码，严格区分 read/write。两者均逐次鉴权；人工批准不替代授权。普通授权读取直接执行，需要确认的操作先取得有效批准。没有授权回调不得执行工具；没有审批通道不得执行需确认的操作。

工具可以是具名、有限范围的业务操作，不等于通用管理执行。禁止把接收任意命令/脚本/配置/目标地址的管理入口注册成工具；单一业务操作须落实 [RFC §6](RFC-001-SERVER-RUNTIME.md#6-受控操作的最小要求) 的影响限制、业务去重、结果确认和审计。只读助手不注册写工具。

工具仅注入完成其职责所需的查询或单一操作接口，不注入全应用 service container、管理连接或凭据集合。Effect、审批标记和幂等声明不是实现或后端权限的证明。

## 场景与措施

| 场景 | 必须落实的措施 | 边界 |
| --- | --- | --- |
| 用户/日志要求执行命令或修改工具定义 | 无通用执行工具；拒绝未知名称、非法 schema 和范围；定义来自宿主 | 文字建议不触发执行 |
| 提示注入导致越权读取或操作 | 每次调用校验当前身份、参数、资源和业务权限，真实后端限权 | 读取仍可能泄密；注入也可能影响结论 |
| 伪造会话、执行或证据 ID | 宿主核对账户/助手/资源归属与读取权限；证据由宿主登记 | 难猜 ID 不替代鉴权 |
| 缺少审批回调或模型伪造“已批准” | 需确认时返回待批准，不执行；只接受可信宿主校验的批准 | 模型或公开事件不能制造批准 |
| 批准后参数、资源、身份或目标状态改变 | 批准绑定账户、操作标识、工具/版本、规范化参数与目标；执行前复核权限和目标状态 | 关键变化重新确认；外部并发修改需业务接口条件检查 |
| 操作超时/取消、重复请求或接管 | 默认不自动重试/重放写；稳定 OperationID 和业务持久去重/结果查询 | 超时可能已经生效；无法确认报告 unknown，不能宣称未执行 |
| 操作只完成一部分 | 明确 partial、实际影响与未完成项；禁止自动扩大操作或自行补偿 | 取消不是回滚；写风险不等同读取 |
| 旧授权、受限历史或长流泄漏 | 宿主筛选当前可见历史，结果/订阅复核权限；每次工具调用重新授权 | 已合法发送的数据不能追回 |
| 任意资源地址或超大响应 | 固定可信 endpoint、资源范围、分页、字节和时间预算 | 配置及真实后端权限由宿主负责 |
| 原始错误、证据或审计泄露秘密 | 入模型前过滤与脱敏，公开字段白名单；业务审计单独授权保存 | 自动脱敏不是完整 DLP |
| 恶意 Go 回调或宿主进程被控制 | 固定构建、代码审查、最小凭据和后端权限 | 嵌入核心无法阻止宿主 RCE 后访问其资源 |

## 最小代码约束

- 无 Goal、Workflow、通用执行或完整个人 SDK 依赖；工具构建时明确注册。
- 模型不能控制 Principal、Definition、连接、审批策略、操作标识或预算。
- 执行链为参数校验 → 预算/取消 → 授权 → 必要审批 → 执行前复核 → 工具 → 过滤/证据/结果。
- 无有效授权不调用工具；无有效批准不执行需确认的操作。
- 写调用默认不自动重试；不确定副作用不得回放成“重试一次”。
- 有界循环和工具超时需底层客户端配合，不能强制杀死不合作的 Go 回调。
- 公开事件不输出私有推理、原始上游正文、Cookie、令牌或完整工具结果。
- 单次上下文隔离；只有不可变定义/连接可共享，不共享可变用户历史。

## 宿主按需承担的责任

登录、历史会话、HTTP/SSE、业务权限、审批 UI/记录、业务幂等及审计留在宿主。安全审计记录账户、操作标识、工具/版本、必要资源标识、影响摘要和结果，不默认复制完整聊天或原始输出。

启用持久后台任务时，宿主另验证调度、领取/租约、旧 worker 提交和恢复；工具调用与最终提交都核验当前执行资格。租约/fence/CAS 不自动保证外部操作只生效一次，也不代替业务去重。即时问答不强制安装这些设施。

代码与依赖安全、容器及网络限制由宿主维护，不因核心精简而取消这些责任；本项目不默认新增服务或修改生产部署。
