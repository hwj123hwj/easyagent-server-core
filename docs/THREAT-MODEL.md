# 嵌入式 Agent 的威胁模型

状态：设计要求，尚未完成实现验收。集成方式为核心源码嵌入宿主应用，不要求独立服务。

## 受信边界

受信代码包括核心、宿主认证/授权、存储及受审查的工具适配器。模型输出、用户问题、日志、对象清单和网络响应不能授予权限。

模型只能看见宿主提供的文本和工具协议；核心不把宿主 DB 管理对象、凭据集合或全应用 service container 暴露给工具执行上下文。工具仅注入必要查询接口，真实后端使用只读权限和有限资源范围。

## 场景与强制措施

| 场景 | 强制措施 | 边界 |
| --- | --- | --- |
| 用户/日志要求执行命令或覆盖配置 | 无命令工具；未知工具拒绝；参数不能指定脚本、URL、SQL、用户或 tenant | 文字建议不触发执行 |
| 间接提示注入导致越权查询 | 每次调用校验当前身份、资源和参数，后端权限限制真实数据访问 | 注入仍可能影响结论；只读也需防信息泄露 |
| 伪造会话、任务或证据 ID | 宿主核对账户/助手/资源归属；证据由宿主登记 | 难猜 ID 不替代鉴权 |
| 旧授权恢复或长流泄漏 | 每步、结果和订阅复核权限，授权查询失败拒绝 | 已合法发送的数据不可追回 |
| 旧 worker 迟到或重复唤醒 | 宿主领取/租约/fence 与提交 CAS；前序完整步骤复用 | 飞行中的读取可能重复 |
| 重连或重复请求造成重复成本 | 幂等键、显式取消、预算、限并发及事件快照 | 未知模型请求仍可能计费 |
| 任意资源地址或超大响应 | 固定受信 endpoint、允许前缀、分页、字节、时间预算 | 配置和后端权限由宿主负责 |
| 原始错误或证据泄露秘密 | 入模型前脱敏、公开字段白名单、日志不打印原始响应/配置 | 自动脱敏不是完整 DLP |
| 恶意 Go 工具适配器 | 仅构建时固定和审查的代码，不上传/加载插件 | 任何 Go 回调都可能使用宿主权限，接口不能强制 OS 沙箱 |
| 宿主进程被完全控制 | 宿主安全措施、最小必要凭据、后端数据权限 | 嵌入核心与宿主共享地址空间，不能宣称阻止宿主 RCE 后的访问 |

## 必须落实的代码约束

- 核心无 Goal、Workflow、命令、SSH、文件编辑和动态工具模块，无完整个人 SDK 依赖。
- 生产执行必须提供身份、权限及必要存储适配器；缺失时拒绝，不默认放行。
- 执行链固定为 schema → 预算/执行权 → 授权 → 查询 → 脱敏/范围过滤 → 证据记录。
- 模型参数不能控制 Principal、助手配置、工具注册、连接或预算。
- 阻止受限历史进入较窄权限上下文；公开历史与原始模型工具历史分开。
- 后台任务恢复重新加载真实账户权限；持久状态与最终事件需原子或等价一致提交。
- CI 检查核心来源、架构依赖和危险执行模块；不粗暴禁止 Go 正常运行时所有 syscall。

## 宿主职责

宿主负责认证入口、业务授权、只读来源连接、来源字段和保留策略。已有应用包含管理功能时，禁止把管理执行接口注册为助手工具；正常管理页面与助手查询是不同能力。

嵌入核心不提供单独进程身份，也不承诺该进程没有其他业务写凭据。代码/依赖安全、非 root/禁止提权、容器和网络限制由宿主既有部署维护；需要改生产配置时依宿主发布约定办理，不默认新增服务或改变 worker 部署。

审计只记录账户、run/step、工具/版本、状态、必要资源标识和关联 ID；不默认复制完整聊天、原始工具输出、Cookie 或令牌。安全审计与受保护会话正文分别存储和授权。
