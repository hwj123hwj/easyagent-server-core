# Source reference and adoption policy

This repository currently contains design documents only. It does not yet
include an Agent implementation or source-adopted EasyAgent runtime.

The design references the public EasyAgent project:

- Upstream: https://github.com/hwj123hwj/easyagent
- Reference commit: `d90804fbe5cf488e6ace810cff925f7cc8b8c6d9`
- Upstream license: MIT, copyright (c) 2026 hwj123hwj

When implementation adopts source files, retain their license and copyright,
record the exact upstream commit, original paths, adopted paths, and local
changes here. Updates require a source diff review and contract validation.

Host application integrations and private business adapters are outside this
repository. Published examples use fictional records and generic contracts.
